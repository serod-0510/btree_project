# B-Tree Based Library Book Search System

This project is the final assignment for the Data Structures course. Our primary objective is to implement an efficient library indexing and book search system by utilizing the **B-Tree** data structure, which is highly optimized for large-scale data retrieval.

## Key Contents
* **B-Tree Theory & Pseudo-code**: A comprehensive explanation of the B-Tree architecture, along with search and insertion algorithms.
* **Library Search System Demo**: A practical demonstration of the Python-implemented, B-Tree-based library book search system.
* **Performance Comparison Lab**: A hands-on performance analysis comparing Binary Search Trees (BST) and B-Trees when processing large volumes of data.
